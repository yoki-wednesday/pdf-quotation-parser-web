🚀 セットアップガイド

Supabase はじめかた・接続手順

PDF見積書パーサー（Web SPA版）とSupabase PostgreSQLデータベースを連携させるためのステップバイステップガイドです。

1

Supabase アカウント作成と新規プロジェクト作成

  1. Supabase 公式サイト にアクセスし、[Start your project] をクリックします。
  2. GitHub アカウント等でサインアップ / ログインします。
  3. [New project] をクリックし、以下を設定します：
    • Name: 例: pdf-quotation-parser
    • Database Password: 強固なパスワードを生成・保存（安全な場所に保管してください）
    • Region: 日本国内運用の場合 Northeast (Tokyo) [ap-northeast-1] を推奨
    • Pricing Plan: Free Tier（無料枠）で十分稼働可能です
  4. [Create new project] を押下し、数分待つとプロジェクトのプロビジョニングが完了します。
2

API設定（URL & anon key）の取得

WebフロントエンドからDBへアクセスするための接続情報を取得します。

  1. 左メニュー下部の [Project Settings]（ギアアイコン ⚙️）をクリックします。
  2. サイドバーの [API]（または Configuration > API）を選択します。
  3. 以下の2つの値をコピーします：
    • Project URL: https://xxxxxxxxxxxxxxxxxxxx.supabase.co
    • Project API keys > `anon` `public`: クライアント向けパブリックキー
⚠️ 注意: service_role キーは絶対に使用・公開しないでください。ブラウザアプリに設定するのは必ず anon (public) キーです。
3

テーブル作成（SQL Editor の実行）

抽出テキストおよび見積メタデータを保存するためのテーブルを作成します。

  1. 左メニューの [SQL Editor] を選択します。
  2. [New query] をクリックし、以下の SQL スクリプトを貼り付けて [Run] をクリックします。
-- 1. パース結果保存用テーブル作成 CREATE TABLE IF NOT EXISTS public.parsed_documents ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), filename TEXT NOT NULL, content TEXT, created_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL ); -- 2. テーブルコメント付与 COMMENT ON TABLE public.parsed_documents IS 'PDFから抽出されたテキストおよびメタデータを保存するテーブル'; -- 3. Row Level Security (RLS) 有効化 ALTER TABLE public.parsed_documents ENABLE ROW LEVEL SECURITY; -- 4. 暫定アクセスポリシー（プロトタイプ検証用: anonキーでの全操作を許可） -- ※本番運用時はユーザー認証（Supabase Auth）と連携したポリシーに切り替えます CREATE POLICY "Allow anon insert and select" ON public.parsed_documents FOR ALL TO anon USING (true) WITH CHECK (true);
💡 解説: ALTER TABLE ... ENABLE ROW LEVEL SECURITY によりRLSが有効化され、安全なポリシー制御の土台が整います。
4

ローカル環境変数（.env.local）の更新

プロジェクトのルートディレクトリにある .env.local を開き、STEP 2 で取得した値に書き換えます。

VITE_SUPABASE_URL=https://your-project-id.supabase.co VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

※ 編集後、開発サーバー（npm run dev）が起動中の場合は自動で再読み込みまたは再起動されます。

5

Web画面からの動作確認

  1. ブラウザで開発サーバーのURL（通常 http://localhost:5173）を開きます。
  2. [ファイルを選択] からお手元のPDF見積書を選択します。
  3. [Extract Text] ボタンをクリックすると、ブラウザ上で pdf.js によるテキスト抽出が行われ、テキストエリアに抽出結果が表示されます。
  4. [Save to DB] ボタンをクリックします。
  5. 「Successfully saved to Supabase DB!」と表示されれば連携成功です！
  6. Supabaseダッシュボードの [Table Editor] > [parsed_documents] を確認すると、保存されたレコードが確認できます。

🛡️ セキュリティ・クラウド非保存ポリシーの遵守について

本Web SPAアーキテクチャでは、「PDFのバイナリファイルそのものはSupabase Storageや外部サーバーに一切送信・アップロードされません」。
ブラウザ（端末メモリ内）の pdf.js で抽出されたテキストデータのみがPostgreSQLへ送信されるため、機密文書のローカル完結・クラウド非保存要件を満たした運用が可能です。
