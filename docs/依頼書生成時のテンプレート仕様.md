# 依頼書生成時のテンプレート仕様書

## 【Background & Purpose】
- **目的**: システム（`pdf-quotation-parser`）から出力する「御見積依頼書 (`ESTIMATE_REQUEST`)」および「御発注書 (`PURCHASE_ORDER`)」の帳票PDFレイアウト、項目構成、スタイル、出力ロジックを明確に定義する。
- **背景**: 欧米式帳票や余剰な検印枠を排し、日本の商習慣に適合したシンプルかつ視認性の高いA4縦型レイアウトを実現する。

---

## 【Decisions】

### 1. 基本仕様・用紙規格
- **用紙サイズ**: A4 縦（`595.28 pt` × `841.89 pt`）
- **マージン**: 左右 `40 pt`（印字有効幅 `515.28 pt`）、上下余白 `40 pt` 以上
- **描画エンジン**: `pdf-lib` + `@pdf-lib/fontkit`
- **フォント**: 日本語フォント埋め込み（Noto Sans JP / YuMincho 等）
  - 通常テキスト: `8.5 pt` 〜 `10 pt`
  - 表題: `22 pt`（太字風二重描画 / 中央揃え）
  - 宛先名: `14 pt`（強調）
- **カラーパレット**:
  - メインヘッダー・アクセント: `rgb(0.1, 0.15, 0.3)` 〜 `rgb(0.2, 0.3, 0.5)`（ネイビー系）
  - 表頭背景: `rgb(0.2, 0.3, 0.5)`（白抜き文字）
  - 偶数行ゼブラ背景: `rgb(0.97, 0.98, 0.99)`
  - 枠線・区切り線: `rgb(0.85, 0.85, 0.85)` / `0.5 pt`

---

### 2. 帳票レイアウト構造

```
+---------------------------------------------------------------+
|                                    依頼番号/発注番号: XXXXX  　 |
|                                    発行日          : YYYY/MM/DD|
|                      【 表 題 】                               |
|                                                               |
| 宛先企業名 御中                     自社名                  　  |
| ご担当: XXX 様                     自社住所 (〒XXX-XXXX)        |
|                                    TEL / FAX                  |
|                                    MAIL / 担当者名             |
|                                                               |
| 挨拶文 (拝啓 貴社におかれましては〜 / 下記の通り〜)           |
| [発注書のみ: ご発注金額 ¥XXX,XXX 円 (下線強調)]               |
+---------------------------------------------------------------+
| 【見積条件】/【発注条件】ボックス                             |
|  ・希望納期 / ・納入場所 / ・回答期限(見積) / ・提示条件等    |
+---------------------------------------------------------------+
| 明細テーブル (ヘッダー: 濃紺背景 / 白文字)                    |
| 項番 | メーカー名 | 品名・仕様 | 数量 | 単位 | [単価 | 金額] | 備考 |
+---------------------------------------------------------------+
| 【特記事項】 (回答方法・送付方法・納期相談等)                 |
+---------------------------------------------------------------+
```

### 3. ヘッダー・発行元情報仕様

#### 3.1. 表題 & 管理番号
| 帳票種別 | 表題 (`title`) | 管理番号ラベル |
| :--- | :--- | :--- |
| **御見積依頼書** (`ESTIMATE_REQUEST`) | `御 見 積 依 頼 書` | `依頼番号: {estimateNumber}` |
| **御発注書** (`PURCHASE_ORDER`) | `御 発 注 書` | `発注番号: {estimateNumber}` |

- **発行日**: `発行日 : YYYY-MM-DD`（指定がない場合は当日日付）

#### 3.2. 宛先表記 (左上)
- **商社・仕入先名**: `{customerName} 御中`（`（株）` は `株式会社 ` に自動展開。空欄時は非表示）
- **担当者名**: `ご担当: {姓} 様`（敬称「様」重複トリム。姓のみ抽出して表記）

#### 3.3. 自社情報 (右上)
- **設定ソース**: `CompanyConfig`（DB / 環境変数 / `config.json` フォールバック）
- **出力項目**:
  - 自社名（`10 pt`）
  - 郵便番号 + 所在地（`9 pt`）
  - 電話・FAX（ハイフン自動付与ロジック適用、`TEL: XX-XXXX-XXXX / FAX: XX-XXXX-XXXX`）
  - メールアドレス（`MAIL: xxx@example.com`）
  - 自社担当者名（`担当: 〇〇`）
- **除外項目**: 角印・社印枠、インボイス登録番号、3連検印枠（日本の商習慣における実務合理化のため非表示）

---

### 4. 挨拶文および条件枠仕様

#### 4.1. 挨拶文
- 共通: `拝啓 貴社におかれましては益々ご隆盛のこととお慶び申し上げます。`
- 見積依頼書: `下記の通り、お見積りをお願い申し上げます。`
- 発注書: `下記の通りご発注申し上げます。`

#### 4.2. 発注金額表記（発注書のみ）
- `ご発注金額: ¥{totalAmount} 円`
- 左寄せ強調（`14 pt`、濃青色）、下部アンダーライン（`1.5 pt`）

#### 4.3. 条件枠（薄グレー背景 0.5pt 枠線）
- **見積依頼書 (`【見積条件】`)**:
  - `・希望納期 : {deliveryDate}`（未指定時は「貴社通常納期」）
  - `・納入場所 : {deliveryPlace}`（未指定時は「自社名（自社住所）」）
  - `・回答期限 : {responseDeadline}`
  - `・提示条件 : 金額は税別（税抜）にてご提示願います。`
- **発注書 (`【発注条件】`)**:
  - `・希望納期 : {deliveryDate}`（未指定時は「貴社標準納期」）
  - `・納入場所 : {deliveryPlace}`
  - `・支払条件 : 貴社とのお取引条件に準ずる`

### 6. 特記事項仕様（フッター上部）
- **見積依頼書**:
  - `・見積書はメール添付（PDF）またはFAXにてご送付をお願いいたします。`
  - `・納期に時間を要する場合は、最短可能納期をご記載ください。`
- **発注書**:
  - `・発注書は本PDFの送付をもって代えさせていただきます。`
  - `・手配漏れなきよう、よろしくお願い申し上げます。`
